# t3Bridge Release Repository (T3 Hub Community Repo)

Official public release & T3 Hub (`T3P v1.0`) distribution repository for **t3Bridge** — Universal P2P Business Application Bridge & Mesh Network for Windows.

## Add to T3 Hub

1. Open **T3 Hub** desktop application.
2. Go to **Repositories** -> **Add Repository**.
3. Enter this repository URL:
   ```
   https://raw.githubusercontent.com/wintararaj-cmd/t3bridge-release/main/
   ```
4. Sync repositories and install **t3Bridge** from the **Discover** tab.
